# Content Plan (stub)

This file will hold the concrete, numbers-and-names content that implements
`docs/GDD.md`: full per-class ability tables, the monster roster per
time-travel level, loot/item tables with tiers and rarity, level themes and
room content, and store inventories. It is intentionally left as a stub in
this planning pass — populate it once the Systems Agent's data schema
(`src/Mutants.Content/*.json` shape) is finalized, so content is written
directly in the load-ready format rather than needing a translation pass.
